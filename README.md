# Pulse

A native Android app built with Kotlin + Jetpack Compose.

## Open and run
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run on an Android 8.0+ device/emulator.

## Notes
- Fully offline.
- No account, network permission, ads, analytics, or backend.
- Local progress is stored with SharedPreferences.
- minSdk 26, targetSdk 35.
